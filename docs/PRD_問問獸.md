# 《問問獸》（或《解題小隊長》）—— 兒童專屬 AI 語音互動家教
## 產品與商業規劃書（PRD & 商業計畫藍圖）2026-10-15

核心目標：用最低的 AI Token 成本，打造「小孩願意用、不會直接抄答案、真正幫父母省下教作業時間」的破圈產品。

### 一、產品定位與核心價值
- 目標受眾：國小 1～6 年級學童（使用者）、雙薪家庭父母／安親班老師（付費與推廣者）
- 解決痛點：
- 小孩端：寫作業遇到不會的題目（特別是文字題、圖表題）沒人問，看文字解析又看不懂
- 家長端：下班太累沒耐心教、怕自己教法跟學校不一樣起衝突；直接給小孩用 ChatGPT 又怕小孩直接抄答案不思考
- 核心差異化（賣點）：
- 「打死不給答案」的蘇格拉底式教育框架：強制將每一題拆解為「3 步驟引導闖關」
- 去文字化（語音＋按鈕雙軌）：全語音對話搭配大圖示按鈕，低年級不識字也能無痛互動
- 極致低成本架構：透過「端側語音＋單次視覺轉文字＋共享題庫」，將單一用戶月成本壓在台幣 5 元以內

### 二、核心使用者體驗流程（五步教育框架）
1. 魔法放大鏡框題：小孩拍下作業或考卷，用「放大鏡框」圈出不會的那一題（強制裁切圖片，節省 70% 視覺 Token 並提高準確率）
2. 題目確認與分流（防呆機制）：視覺 AI 啟動（僅此一次）辨識圖片內容，若非作業（如拍貓咪、玩具），虛擬角色直接裝傻拒答；語音確認：「我看題目是說『小明有 15 顆蘋果……』，還有畫一個時鐘指著 3 點，對嗎？」小孩按才進入教學
3. 三關卡蘇格拉底式互動（核心框架）：系統將小孩鎖定在 3 個回合內解決問題，採用「對講機按住說話 ＋ 畫面雙選項按鈕」：
- 第一關（抓重點／讀題）：AI 問：「題目最後想問我們什麼？是問『剩下多少』還是『全部多少』？」（畫面同步出現兩個按鈕，小孩可說可點）
- 第二關（想方法／邏輯）：AI 問：「那你覺得要把這兩個數字『加起來』還是『減掉』呢？為什麼？」
- 第三關（自己算／驗證）：AI 說：「太棒了！那現在請你在紙上算算看，算出來答案是多少告訴我！」
4. 過關獎勵與盲點紀錄：答對後給予角色升級獎勵；系統在後台自動記錄：「該生今日卡關點：看不懂『相差』代表減法」
5. 家長端「學情翻譯紙條」：立即或每週推播給家長：「寶貝今天自己解開了 3 道數學題！他原本搞不懂『倍數』的概念，經引導後已經自己想通囉（附小孩講解的 5 秒可愛錄音）」

### 三、技術與省錢架構設計
| 層級 | 推薦技術方案 | 省錢與防呆策略 | 預估成本 |
|---|---|---|---|
| 前端 App | Flutter 或 React Native | 一套程式碼同時打包 iOS 與 Android，搭配 Rive / Lottie 做輕量級 2D 虛擬角色嘴型同步動畫 | 開發成本最低 |
| 語音轉文字 (STT) | iOS Speech Framework / Android SpeechRecognizer（手機端內建） | 完全不經過雲端收費 API | 0 元（免費） |
| 視覺辨識 (Vision) | Gemini 2.5 Flash 或 GPT-4o mini | 圖片上傳前先在手機端壓縮至 800x800px 以內；辨識完立刻轉化為結構化文字描述（JSON），後續對話不再傳送圖片 | 每題約 NT$ 0.01~0.03 |
| 家教大腦 (LLM) | 輕量級模型 ＋ Prompt Caching | 各年級課綱、蘇格拉底教學劇本設為 System Cache（打 1 折）；限制 AI 每次回覆不超過 60 個字 | 每題（來回 4 句）約 NT$ 0.02 |
| 文字轉語音 (TTS) | 預錄音檔庫 ＋ Edge TTS / OpenAI Audio mini | 100 句常用串場語預先生成包在 App 裡免費播；只有講解題目的那一句才動態生成 | 每題約 NT$ 0.05 |
| 後端與題庫快取 | Supabase (PostgreSQL + pgvector) | 向量題庫共享：A 小孩拍過的題目轉成向量存入資料庫，B 小孩拍同一題直接調用已生成的三步驟引導劇本 | 重複題目成本 0 元 |

成本總結：單題完整流程（拍照＋講 4 句話＋聽語音）不到台幣 0.1 元；免費試用 50 題僅約台幣 5 元獲客成本。

### 四、核心 AI 教育框架設定（System Prompt 結構）
後端傳給 AI 的系統指令採用「狀態機」概念，強制 AI 輸出 JSON 格式：
```json
{
"role": "溫暖且有耐心的國小伴讀小怪獸",
"rules": [
"絕對禁止直接說出最終答案或完整算式，違者任務失敗。",
"每次發言必須控制在 40 字以內，使用台灣國小生聽得懂的口語。",
"必須同時提供 2 個簡短的『提示按鈕文字』，讓不知道怎麼開口的小孩可以用點的。"
],
"current_stage": "STAGE_1_UNDERSTAND_QUESTION",
"output_format": {
"spoken_text": "家教要唸出來的台詞",
"ui_choices": ["選項A", "選項B"],
"is_solved": false,
"parent_insight": "記錄小孩這一步卡在哪裡（給家長看的簡短分析）"
}
}
```

### 五、商業模式與冷啟動推廣策略
1. 雙軌制商業模式（Freemium）：
- 免費版：每天可免費拍照問 3 題（每天成本不到台幣 0.3 元），支援基礎語音互動與三步驟引導
- 家長無憂訂閱制（每月 NT$ 190 或每年 NT$ 1,690）：無限題數拍照與語音提問；「錯題變身術」（AI 改數字生成雙胞胎練習題）；家長專屬 Line 週報（卡關盲點＋解題錄音精華）
2. 零廣告費推廣三部曲：
- 第一步：攻佔安親班與個人家教做種子用戶（B2B2C），免費送班級帳號
- 第二步：「Line 家長學習小紙條」病毒裂變（炫耀卡轉發，雙方得免費 10 題額度）
- 第三步：切入高痛點單一題型做社群短影音（Threads、IG Reels）

### 六、開發路線圖（MVP 四階段）
- 第 1～2 週（PoC 概念驗證）：先不寫 App 介面；鎖定國小三年級數學應用題，用網頁版（或 Line Bot）串接 Gemini Flash API，把「拍照 → 3 步驟 JSON 提示詞 → 語音唸出」劇本調校到不會破功、不會直接給答案
- 第 3～5 週（MVP）：用 Flutter 做出單一核心畫面（會動嘴巴的虛擬角色＋題目裁切圖＋按住說話大按鈕＋兩個提示選項按鈕）
- 第 6 週（真人小孩封測）：找 5～10 個國小生實際拿回家寫作業用一週，觀察卡關點
- 第 7～8 週（家長報表＋收費機制，正式上架）：串接 Line 推播＋ Apple/Google 內購訂閱，啟動媽媽群組與安親班推廣
