# 《問問獸教學系統》完整規劃書 v2（2026-10-16）

> v1 是單一「拍照問答」PoC。v2 格局放大：問問獸只是其中一個功能，
> 最終目標是一整套「在有趣中建立學習興趣」的國小教學系統。

## 一、產品願景

讓國小 1–6 年級的孩子**主動想打開來玩**，在遊戲化的互動中建立對數學的興趣，
而不是被逼著寫作業。家長看到的是孩子的進步，不是哭鬧。

## 二、功能架構（三大模組）

### 模組 A：🦖 問問獸（拍照問答）— 已有
- 拍照 → 框選 → AI 辨識 → 三關卡蘇格拉底引導 → 獎勵
- 核心鐵律：**死不給答案**，小孩必須自己算出每一個數字
- 定位：寫作業卡關時的「伴讀小幫手」

### 模組 B：🎲 隨機出題（分級闖關）— 本次新增
- 按年級分三級：**低年級（1–2）**、**中年級（3–4）**、**高年級（5–6）**
- AI 隨機出題，小孩作答，答對得分、答錯引導
- 定位：平時沒事也能玩的「數學遊戲機」，在玩樂中練習

#### 出題範圍
| 年級 | 內容 |
|------|------|
| 低年級 | 20 以內加減、簡單應用題、認識圖形、比大小 |
| 中年級 | 乘除法、兩位數加減、分數入門、簡單幾何 |
| 高年級 | 分數四則、小數、面積體積、比例、速率 |

#### 遊戲規則
- 每輪 5 題，答對 +10 分，連續答對有連擊加成（x2、x3…）
- 答錯不扣分，問問獸用提示引導再試一次（最多 2 次）
- 完成一輪給星星評價（5 題全對 = 3 星）
- 計入家長儀表板：今日挑戰次數、平均分數、弱點題型

### 模組 C：🏆 成長系統（未來）
- 怪獸升級進化：答對累積經驗值，問問獸長大、換造型
- 徽章收集：連擊王、應用題達人、幾何小天才等
- 每日任務：每天 3 道精選題，連續完成給獎勵
- 錯題本：自動收集答錯的題目，改數字重新出題練習
- 家長週報：Line 推播學習報告

## 三、技術架構（沿用 v1，補充 B 模組）

| 模組 | 技術 | 成本 |
|------|------|------|
| 出題 | Gemini 輕量模型，按年級 prompt 生成題目 JSON | 每題約 NT$0.01 |
| 判題 | 本地比對（數字題）或 AI 判斷（應用題） | 幾乎 0 元 |
| 遊戲化 | 前端 localStorage 記分數、連擊、徽章 | 0 元 |

出題 JSON 格式：
```json
{
  "question": "小明有 15 顆蘋果，吃掉 7 顆，還剩幾顆？",
  "answer": "8",
  "hint": "想想看：原本有 15 顆，少了 7 顆，是變多還是變少？要用加法還是減法？",
  "grade": "低年級",
  "type": "應用題"
}
```

判題鐵律：
- 數字答案：直接比對，容許全形半形、空格差異
- 答錯時：**不直接給正確答案**，先給 hint 引導再試一次
- 兩次都錯：公布答案並講解思路（這是測驗不是作業引導，可以講解）
