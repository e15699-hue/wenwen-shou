# 問問獸開發進度（2026-10-16 凌晨）

## 網頁 PoC（https://e15699-hue.github.io/wenwen-shou/）

### 本輪新增功能
1. **魔法放大鏡框題**：拍照後可用手指在圖上框選題目區域（canvas 實作，支援觸控＋滑鼠），只送框選部分給 Gemini，省 70% Token 並提高準確率；也可選「用整張照片」
2. **家長儀表板**：顯示今日解題數、星星數、對話輪數、卡關點紀錄（自動同步 AI 的 parent_insight）
3. **過關獎勵動畫**：答對時 40 個 emoji 彩帶從天而降＋星星爆發動畫＋3 顆星
4. **兒童化 UI**：按鈕更大（19px 字體）、對話泡泡字體放大、語音選擇器（可試聽不同中文語音）
5. **除錯模式**：可勾選顯示 AI 原始 JSON（給開發者看思考過程）

### 技術要點
- 模型：`gemini-3.5-flash-lite` 優先（輕量省錢），依序備援 `gemini-3.1-flash-lite`、`gemini-flash-lite-latest`、`gemini-3.5-flash`
- 每個模型 503 時重試 2 次（等 2秒、4秒），再換下一個
- 30 秒超時保護
- **鐵律**：AI 絕對禁止說出任何計算結果（含中間步驟），小孩必須自己算每一個數字
- API Key 只存瀏覽器當次頁面記憶體，永不進 Git

### 已知問題
- `gemini-2.5-flash-lite` 對新用戶回 404（已改用 3.5-flash-lite）
- `gemini-3.8-flash` 等預覽版常 503（已加入自動容錯）
